# Proyectos

## Página Web Jaziz

Una página web construida para la marca de mi mama Jaziz. Un emprendimiento basado en 
articulos de bisuteria como pulseras, collares, aretes, anillos etc. Hecho en VisualStudioCode.
Esta página tiene un elemento 3D animado el cual se muestra en formato de video en el primer
instante en el que entra a la página. Esta página sigue en proceso ya que se busca mejorarla mientras más conocimiento y avanze se valla viendo en la U.

## Página Web GlobalSeguros

Una página web construida para la empresa GlobalSeguros, la cual se dedica al servicio de todo tipo de seguros, pero el enfoque principal de la página fue de los seguros educativos. Hecho en VisualStudioCode.
Fue desarrolada como parte de un reto llamado el hackton, en el que la empresa buscaba ver ideas 
más dinamicas que mostrara este servicio de una manera mucho más creativa y original. En esta página se tuvo en cuenta errores de la página de GlobalSeguros, la cual contiene mucha info y colores muy fuertes que pueden afectar la experiencia del usuario.
